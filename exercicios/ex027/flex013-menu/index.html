Conceitos básicos de flexbox

O Flexible Box Module, geralmente chamado de flexbox, foi projetado tanto como um modelo de layout unidimensional quanto como um método capaz de organizar espacialmente os elementos em uma interface, além de possuir capacidades avançadas de alinhamento. Este artigo fornece um resumo das principais funcionalidades do flexbox, as quais exploraremos com mais detalhes no restante deste guia.

Quando se descreve o flexbox como sendo unidimensional, enfatiza-se o fato de que ele lida com o layout em uma dimensão de cada vez - seja uma linha ou uma coluna. Isto pode ser comparado com o modelo bidimensional de CSS - Layout de Grade, que permite o controle simultâneo das colunas e linhas.

Os eixos do flexbox

Conforme descrito acima, a propriedade flex-direction define a direção do eixo principal e pode tem quatro valores possíveis:

  • row
  • row-reverse
  • column
  • column-reverse

Se o valor escolhido for row (linha) ou row-reverse (linha reversa), seu eixo principal se moverá ao longo da linha — na direção inline.

Justify Content

O The justify-content propriedade é usada para alinhar os itens do eixo principal, direção em que flex-direction tem definido o fluxo. O valor inicial é flex-start que alinhará os itens na borda inicial do container, mas você também pode definir o valor para flex-end para alinhá-los no final, ou center para alinhá-los no centro.


Você também pode usar o valor space-between para ter todo o espaço livre depois que os itens foram dispostos, e compartilhá-lo uniformemente entre os itens para que haja uma quantidade igual de espaço entre cada item. Para causar uma quantidade igual de espaço à direita e à esquerda (ou superior e inferior para colunas) de cada item use o valor space-around. Com space-around, os itens têm um espaço de meio tamanho em cada extremidade. Ou, para fazer com que os itens tenham espaço igual ao seu redor, use o valor space-evenly. Com space-evenly, os itens têm um espaço em tamanho real em qualquer extremidade.


Experimente os seguintes valores de justify-content:

  • start
  • end
  • left
  • right
  • normal
  • flex-start
  • flex-end
  • center
  • space-around
  • space-between
  • space-evenly
  • stretch

O artigo Alinhando itens em um recipiente flex explora mais a fundo essas propriedades, a fim de ter uma melhor compreensão de como funcionam. Esses exemplos básicos, no entanto, são úteis na maioria dos casos de uso.

Justify Items

A propriedade justify-items define o valor padrão de justify-self para todos os itens dentro de um container, alinhando-os ao longo do eixo inline (horizontal) do container. No contexto do flexbox, essa propriedade não tem efeito direto para flexbox, utilize justify-content para alinhar os itens no eixo principal.


No entanto, em outros contextos de layout como Grid, justify-items é bastante útil. Os valores possíveis incluem:

  • auto
  • normal
  • start
  • end
  • center
  • stretch
  • flex-start
  • flex-end
  • self-start
  • self-end
  • left
  • right

Para controlar o alinhamento de um único item dentro do container flex, utilize a propriedade align-self diretamente no item desejado.

Align Items

A propriedade align-items define o comportamento padrão de como os itens flex são dispostos ao longo do eixo transversal (cross axis) da linha atual. Pense nisso como a versão do justify-content para o eixo transversal perpendicular ao eixo principal.


O valor inicial de align-items é stretch, que fará com que os itens se estiquem até a altura do item mais alto da linha. Você pode alterá-lo para flex-start para que os itens se alinhem ao início do container, flex-end para alinhá-los ao final, ou center para centralizá-los.


Experimente os seguintes valores de align-items:

  • stretch
  • flex-start
  • flex-end
  • center
  • baseline
  • start
  • end
  • self-start
  • self-end
  • normal

Para sobrescrever o alinhamento de um item específico, utilize a propriedade align-self diretamente no elemento filho desejado. Ela aceita os mesmos valores que align-items.

Flex Flow

A propriedade flex-flow é uma propriedade shorthand que combina flex-direction e flex-wrap em uma única declaração. Ela define simultaneamente o eixo principal do container flex e se os itens podem ou não quebrar para múltiplas linhas.


A propriedade flex-wrap controla se o container flex é de linha única ou multilinha, e a direção do eixo transversal, que determina a direção em que novas linhas são empilhadas. O valor inicial é nowrap, que faz com que todos os itens fiquem em uma única linha, o que pode causar overflow caso os itens sejam muito largos.


Valores possíveis para flex-direction:

  • row
  • row-reverse
  • column
  • column-reverse

Valores possíveis para flex-wrap:

  • nowrap
  • wrap
  • wrap-reverse

Exemplo de uso da shorthand: flex-flow: row wrap define os itens em linha e permite a quebra para novas linhas quando necessário.

Flex

A propriedade flex é uma shorthand que define como um item flex cresce ou encolhe para se ajustar ao espaço disponível no container. Ela combina três propriedades: flex-grow, flex-shrink e flex-basis.


flex-grow define o fator de crescimento do item em relação aos demais itens do container. flex-shrink define o fator de encolhimento quando não há espaço suficiente. flex-basis define o tamanho inicial do item antes de o espaço disponível ser distribuído.


Valores comuns da shorthand flex:

  • flex: 1 — o item cresce para preencher o espaço disponível
  • flex: auto — equivalente a flex: 1 1 auto
  • flex: none — equivalente a flex: 0 0 auto, item inflexível
  • flex: initial — equivalente a flex: 0 1 auto, valor padrão
  • flex: 2 — o item cresce o dobro em relação a um item com flex: 1

É recomendado utilizar a shorthand flex ao invés das propriedades individuais, pois ela redefine automaticamente as outras sub-propriedades para comportamentos comuns de forma mais previsível.
